# Jess' Dog Organiser (JDA)

A mobile-first dog walking and sitting organiser based on the supplied spreadsheet structure.

## Included

- Dog profiles: image, name, breed, age, owner's name, address, key-to-premises status, special requirements and other notes.
- Separate walking and sitting toggles with multiple weekly day/time entries.
- Today screen for scheduled jobs.
- Searchable All Dogs directory.
- Weekly Walking and Sitting screens.
- Pickup route selector that opens chosen saved addresses in Google Maps.
- Local device storage with JSON backup and restore.
- No account, API key or backend required for this first version.

The app is designed as a simple static mobile web app so it can be hosted directly from this repository.
